Common questions

Will I lose my progress if I get a new phone?

Not if iCloud is on. The game saves your progress to your own iCloud, so it appears on any iPhone signed in to the same Apple Account. You can also copy a save code from the game's Saves page and keep it somewhere safe.

My progress didn't show up on my other device.

Check that both devices are signed in to the same Apple Account with iCloud turned on, then close the game fully on both and open it on the device you want to play on. If it still doesn't arrive, use a save code from the Saves page.

Does the game earn while it's closed?

Yes. Your holding keeps working while you're away, and you're paid for that time when you come back. Your hunting party eats food while it works, so if food is running down, check what the party is costing you.

What's “End family line”?

It deletes your whole family and starts the game over from nothing, which is why it asks four times. It can't be undone unless you saved a save code first.

Do I need Game Center?

No. Game Center adds leaderboards and achievements; the game plays the same without it.

Does the game need the internet?

No. It plays fully offline. iCloud saves and Game Center catch up when you're back online.
